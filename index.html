YouTube Hub

設定

Google Cloud ConsoleでYouTube Data API v3を有効化して発行したAPIキーを貼り付けてください（README参照）。

ダッシュボード内のプレイヤーで、動画の再生時間に対してこの割合以上再生した時点で自動的に「視聴済み」として記録します。

「登録チャンネルの新着」「今日のニュース」のサムネイルに再生時間バッジ、説明欄に再生数（例：3.2万回視聴）を表示します。オンにするとYouTube Data APIの`videos.list`呼び出しが追加で発生します（表示対象の動画IDをまとめて渡すため、1回の更新あたり概ね+1〜3ユニット程度の見込みです）。

「登録チャンネル一覧に表示」をオフにすると、そのチャンネルは「登録チャンネルの新着」セクションには表示されず、ニュース対象にした場合はニュース欄のサジェスト元としてのみ使われます。「表示件数」は「登録チャンネルの新着」に並べる動画の最大本数、「直近n日以内」は公開からn日を超えた動画を除外する設定です（空欄なら期間の制限なし）。登録後もチャンネル一覧の各項目（表示件数・日数の変更、↑↓ボタンでの並べ替え）からいつでも変更できます。

      設定はこのブラウザのlocalStorageにのみ保存されます（サーバー送信なし）。APIキーを他人と共有しないでください。
